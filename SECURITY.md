# Security Policy

`lcr` runs a local HTTP server and can type text into tmux panes, so security issues matter even though it's a local tool.

## Reporting a vulnerability

Please **don't** open a public issue. Use GitHub's [private vulnerability reporting](../../security/advisories/new) instead. You'll get a response as soon as possible, and a fix will be released before details are made public.

## Supported versions

Only the latest version on `main` is supported.
